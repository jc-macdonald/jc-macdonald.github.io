Computed software examples

Spatial fields, stochastic simulations, replicated comparisons and incomplete-data reconstruction using released packages.

These examples use released versions of OP System, OP Engine, trade-study and VBPCApy. All data are synthetic. The plots show computations rather than findings from an application study; their captions state the assumptions and what is checked.

Spatial diffusion

OP System compiles a named-axis expression for a periodic diffusion stencil; OP Engine integrates the resulting field with fourth-order Runge–Kutta (RK4). The stencil is supplied explicitly on 64 equally spaced cells. Faster spatial variation fades sooner than slower variation.

The code checks the full trajectory against the exact Fourier-mode solution of the discrete spatial stencil, with a maximum absolute difference below 2e-10. This measures temporal integration error for the chosen grid. It does not measure error against a continuum PDE or establish accuracy for other spatial discretizations.

Stochastic transfers

OP Engine runs 512 independent realizations of a two-state transfer process using the exact stochastic simulation algorithm (SSA), with one event clock per run. Each starts with 40 units; each remaining unit transfers at rate 0.6. The example retains the accepted firing counts and checks conservation and the correspondence between counts and transferred units.

Replicated designs

trade-study evaluates ten sample-mean designs using 512 paired replicates. The measurement standard deviation is either 1 or 1.5. The noisier measurement is assigned a lower cost; the standard measurement has a fixed setup cost. Those costs are illustrative assumptions. The circles mark designs for which no alternative improves both mean error and assumed cost.

The table reads the same generated data as the figure. Error estimates depend on these 512 simulated replicates. A design is nondominated when no other design is at least as good on both stated objectives and better on at least one. Choosing a design for an application also requires preferences or constraints relevant to that application.

Incomplete data

VBPCApy fits a two-component model to observed entries of a noisy synthetic matrix. Roughly 35% of entries are withheld, shown in gray. The generating signal uses two patterns; that choice is supplied to the fitted model.

The root mean squared reconstruction error on withheld noisy observations is about 0.22 for this seeded example; the generating noise standard deviation is 0.2. This is one reconstruction check with a known component count. Choosing the rank and assessing uncertainty calibration require separate studies.
