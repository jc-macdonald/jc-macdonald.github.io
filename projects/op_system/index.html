OP System

Describe models of changing systems, including spatial interactions and random events.

OP System turns readable model descriptions into calculations for simulation. It supports partial differential equations (PDEs) with spatial or trait structure, nonlocal interactions, compartmental flows, ordinary differential equations (ODEs) and stochastic reaction networks. Researchers specify equations or transitions; the compiler produces numerical evaluators for NumPy, JAX and PyTorch.

Public alpha release on PyPI · v0.9 documentation and executable examples

Named axes describe groups, space and traits. Model interfaces expose reactions, operators, named latent observables and time-varying parameters. OP Engine can use these interfaces for simulation; measurement-error and observation models belong in downstream analyses. Other numerical tools can consume the compiled calculations.

Numerical consumers choose spatial discretization and time or event integration. Validation checks expressions, shapes and interface contracts. Cross-axis constraints are recorded as metadata and do not filter state cells or transitions. Numerical accuracy and scientific adequacy need checks for the intended application.
