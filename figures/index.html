OP stack demonstrations

Each figure shows one design choice of the OP stack on a synthetic model with an independent check, using released OP System 0.10.0 and OP Engine 0.9.1 with JAX and CPU PyTorch. No timings are plotted; single-call wall-clock values are retained in the data file with the CPU model for the record. The computed examples page states what each figure supports and its limits.
