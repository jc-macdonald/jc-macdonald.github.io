Research Profile

  • Computational scientist whose overarching interest is how ecological and landscape change influences the movement and connectivity of hosts, pathogens and cultural traits, and through them the persistence and evolution of structured populations. Established work addresses within- and between-host dynamics, including viral and immunological models from within-host to population scale, and cultural transmission; landscape-scale questions are a developing direction. Builds mechanistic models, inference methods and research software. Applications include infectious disease, public and global health and ecology; methods work also addresses incomplete data. Developing work includes scientific machine learning and the design of monitoring programs and studies with field and domain partners.

Research Themes

  • Within individuals Viral growth, immune response and antibody kinetics and their consequences for transmission (foot-and-mouth disease, dengue; Crimean-Congo hemorrhagic fever in progress).

  • Across populations Published work on cultural variation across geography and language. Developing: how landscape change, movement and contact shape spread, persistence and divergence.

  • Decisions Surveillance and control decisions for livestock and wildlife disease, vaccination and scenario modeling under uncertainty, and study-design comparison.

Study Systems

  • Foot-and-mouth disease virus in African buffalo Within-host model (first author) and carrier-transmission model (co-author); senior personnel on a multi-institution project.

  • Crimean-Congo hemorrhagic fever virus in livestock and wildlife Collaborative transmission models and surveillance design.

  • Human cultural transmission Networks and clusters of cultural traits across Austronesian-speaking societies; methods for incomplete cultural data.

Research Software -- Lead Developer

  • OP System (Operator-Partitioned System)

    2026–present

    Turns readable model descriptions into calculations for simulation and data analysis. Handles spatial structure, interactions between groups and random events in disease, ecological and other dynamical models.

    • Release status: Public; package maturity: alpha; latest released version: v0.10.0 (final). PyPI · Release archive · All versions
    • Source

  • pp-eigentest

    2026–present

    Research on distinguishing underlying patterns from noise in incomplete data. Revises a 2024 preprint and studies how missing observations and modeling assumptions affect that choice. Evaluation studies and manuscript revision are in progress.

    • Release status: Private; package maturity: alpha; unreleased.
    • Project summary

  • op_infer (Inference and Calibration)

    2026–present

    Connects scientific models with data to estimate unknown quantities and compare data-collection plans. Tests fitting procedures on simulated data under stated modeling assumptions. Broader interfaces and application studies remain in development, and application materials remain private.

    • Release status: Public; package maturity: pre-alpha; unreleased on PyPI (development version 0.0.1). Citation metadata
    • Source · Project summary

  • Trade Study (Python)

    2026–present

    Compares model settings, experiments and surveillance plans using repeated simulations. Helps researchers assess uncertainty and weigh competing goals such as accuracy, information and cost.

    • Release status: Public; package maturity: alpha; latest released version: v0.6.0 (final). PyPI · Release archive · All versions
    • Source

  • OP Engine (Operator-Partitioned Engine)

    2025–present

    Simulates models that change over time and space, including systems with random events. Supports repeated simulations and summaries of quantities such as population counts. Capabilities and numerical checks depend on the selected method.

    • Release status: Public; package maturity: alpha; latest released version: v0.9.1 (final). PyPI · Release archive · All versions
    • Source

  • vbpca-py

    2024–present

    Finds patterns in incomplete datasets without first filling in every missing observation. Produces low-dimensional summaries and variational covariance estimates, with tools for checking fit and choosing the number of summary dimensions.

    • Release status: Public; package maturity: beta; latest released version: v0.5.0 (final). PyPI · Release archive · All versions
    • Source
